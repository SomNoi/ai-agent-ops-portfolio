- **ฝึกและเตรียมเอเจนต์:** กฎระบบ (SOUL.md / WORK_RULES) ไฟล์สกิล (SKILL.md) ชุดปฐมนิเทศ คลังสกิลกลาง
- **ความเสถียร / AgentOps:** เปิดเองตอนบูตด้วย Task Scheduler, watchdog พร้อมทดสอบ kill, บันทึกเพื่อทำงานต่อหลังรีสตาร์ท, แจ้งเตือน RAM/ดิสก์, แก้ปัญหา timezone/cron, หาสาเหตุราก, อัปเกรดเวอร์ชัน
- **ระบบอัตโนมัติและการเชื่อมต่อ:** Gmail, Google Calendar, Google Drive, Slack, GitHub, MCP, แดชบอร์ดเว็บสด, ส่งออก draw.io
- **ระเบียบวิธีวิจัยเชิงปริมาณ:** ลงทะเบียนสมมติฐานล่วงหน้า, Bonferroni, ข้อมูล holdout ที่ไม่แตะ, ต้นทุนจริง, เกณฑ์ Wilson lower bound, พอร์ต Python เป็น MQL5
- **งานปฏิบัติการและเทคนิค (จากงานเดิม):** ตั้งเครื่องและตรวจงาน CNC (work offset, ตรวจชิ้นแรกและระหว่างผลิตตามแบบ) · ไอทีซัพพอร์ต (ลง Windows, ติดตั้งซอฟต์แวร์และจัดการไลเซนส์) · Adobe Illustrator / Photoshop · Facebook Ads · บริหารสต็อกสินค้า · การผลิตและควบคุมคุณภาพงานตัดเย็บ

## ผลงานเด่น (ก.ย.–ต.ค. 2026)
**ทีม AI หลายเอเจนต์ (ผู้ออกแบบและผู้ดูแล)**

- บอทหัวหน้า 1 ตัวดูแลบอทผู้เชี่ยวชาญ 5 ตัว (ทดสอบแบบ paper, คัดกรอง Gmail, backtest FX, มอนิเตอร์ทีมแบบสด, แดชบอร์ด) และ Hermes Agent (โอเพนซอร์สจาก Nous Research) ที่ติดตั้งเองอีก 2 ตัว: ตัวหนึ่งบน Windows VPS ที่รัน MetaTrader 5 อีกตัวบนพีซีที่บ้าน
- บอทย่อยรายงานหัวหน้าเท่านั้น งานแต่ละประเภทมีบอทเจ้าของตัวเดียว และต้องขออนุมัติก่อนทำงานที่เกี่ยวกับเงิน การลบข้อมูล หรือการเทรดจริง

**ชุดปฐมนิเทศเอเจนต์และคลังสกิลกลาง**

- เขียนกฎการทำงานและชุดสกิล 8 ตัว (รับงานและวางแผน, ตรวจ Windows อย่างปลอดภัย, ล้างดิสก์อย่างปลอดภัย, ดูสถานะ MT5 แบบอ่านอย่างเดียว, แจ้งความคืบหน้าและ ETA, ดูแลข้อมูลลับ, กู้คืนเมื่อเกิดปัญหา, รายงานหัวหน้า) พร้อมสคริปต์ติดตั้งที่สำรองไฟล์และย้อนกลับได้
- สร้างสกิลกลาง: ส่งต่อคำสั่งแบบ paste-block, ETA/แจ้งเมื่อล่าช้า, ดูแลข้อมูลลับ, ระบุแหล่งข้อมูล, ด่านกรองงานประจำ

**เอเจนต์ที่ฟื้นตัวเองได้บน Windows**

- เปิดอัตโนมัติตอนบูตและมี watchdog ตรวจทุก 5 นาที ทดสอบ kill แล้ววัดเวลากลับมาทำงานได้ราว 20 วินาทีและ 140 วินาที
- หาสาเหตุรากของบั๊ก run-as-SYSTEM และการอัปเดตล้มเหลวเพราะ venv ถูกล็อก อัปเกรด Hermes จาก v0.20 / v0.21.3 เป็น v0.21.7

**ให้เอเจนต์ดูแลพีซี**

- เพิ่มพื้นที่ว่างไดรฟ์ C: จาก 7.2 GB เป็นราว 26–30 GB อย่างปลอดภัย (มี restore point, changelog, สคริปต์ undo และจัดไฟล์ด้วยการย้ายเท่านั้น ไม่ลบ)

**ไปป์ไลน์วิจัยกลยุทธ์อย่างเข้มงวด**

- ทดสอบกลยุทธ์ราว 645 ชุดที่ลงทะเบียนไว้ล่วงหน้า ใช้ Bonferroni, holdout 12 เดือนที่ไม่แตะ, ต้นทุนโบรกเกอร์จริง และเกณฑ์ Wilson lower bound **ผลตามจริงคือไม่มีกลยุทธ์ใดผ่านเกณฑ์**

- พอร์ต EA REB-H4 จาก Python เป็น MQL5 ได้ผลตรงกับต้นแบบ 5/5 วัน ตอนนี้ทดสอบต่อบนบัญชีเดโมเท่านั้น โดยส่งสัญญาณจาก Python ไป MT5 ผ่านไฟล์

**ระบบอัตโนมัติ Gmail และแดชบอร์ด**

- แจ้งเตือนบิลด่วน/OTP โดยไม่ส่งตัวรหัส และสรุปอีเมลทุกเช้า
- แดชบอร์ดเว็บแสดงกิจกรรมของทีมบอทแบบสด ส่งออกไฟล์ .drawio ผ่าน draw.io MCP
