# bot-install-checklist

ใช้เมื่อจะติดตั้งโปรแกรมบนเครื่องบอท (shared Linux box) หรือเมื่อผู้ใช้ถามว่าติดตั้งอะไรคุ้ม/ไม่คุ้ม

## ข้อเท็จจริงเครื่อง (ตรวจใหม่ทุกครั้งถ้าเป็นไปได้)
1. รัน `df -h /` — ดิสก์เป็นของรวมทุกบอท ไม่มีโควต้าแยกต่อตัว
2. บอทแยกกันแค่เดสก์ท็อป/หน้าจอ ไม่แยกฮาร์ดดิสก์
3. รายงานสั้น: ขนาดรวม / ว่าง / % ที่ใช้

## กติกาเน็ตก่อนติดตั้ง
ก่อนลงอะไรที่ต้องคุยเซิร์ฟเวอร์ภายนอก ให้แยก 2 ชั้น:
- **ชั้นเว็บ (มักผ่าน):** HTTPS พอร์ต `443` → ดาวน์โหลดจากเว็บไซต์โบรก/ติดตั้งได้
- **ชั้นเทรด/ฟีด (มักบล็อกบนเครื่องบอท):** พอร์ตเทรดเฉพาะโบรก (เช่น `1950` `4433` `5011` `5021` ฯลฯ) → ล็อกอินชื่อขึ้นได้ แต่ไม่มีโควต/ฟีด `0 Kb`

ทดสอบเร็ว (ตัวอย่าง):
```bash
timeout 3 bash -c 'echo >/dev/tcp/<host>/443' && echo OK || echo FAIL
timeout 3 bash -c 'echo >/dev/tcp/<host>/<trade_port>' && echo OK || echo FAIL
```

ถ้าชั้นเทรด FAIL → **ห้ามติดตั้งเพื่อดึงราคาจริง** จนกว่าจะมีหลักฐานว่าพอร์ตเปิด

## ตารางตัดสินใจเร็ว

| ประเภท | ติดตั้งบนเครื่องบอท? | เหตุผล |
|--------|----------------------|--------|
| CLI / Python / Node / ไลบรารีวิเคราะห์ | ใช่ (ถ้าพื้นที่พอ) | ไม่พึ่งพอร์ตเทรด |
| เบราว์เซอร์งานเว็บ / connector | ใช่ตามงาน | ใช้ 443 เป็นหลัก |
| MT4 / MT5 / cTrader เพื่อดึง OHLC จากโบรก | **ไม่** (จนกว่าพอร์ตเทรดเปิด) | โหลด+ล็อกอินได้ แต่ฟีดมักไม่มา — เปลืองที่ |
| MT4 / MT5 / cTrader เพื่อยิงออเดอร์จากเครื่องนี้ | **ไม่** จนกว่าพอร์ตเทรด + สภาพแวดล้อมรองรับ | เสี่ยงบล็อกเดียวกัน |
| ดาวน์โหลดตัวติดตั้งจากเว็บโบรก | ได้ | แต่ “ได้ไฟล์” ≠ “ใช้ฟีดได้” |

## ทางเลือกแทนเมื่อต้องการราคาโบรก
1. แหล่งสาธารณะชั่วคราว (เช่น Yahoo) — ติดป้ายชัดว่าไม่ใช่แท่งโบรก
2. ให้ผู้ใช้ส่ง CSV จากเครื่อง/VPS ที่ต่อโบรกได้
3. ใช้ trading VPS ที่เปิดพอร์ตโบรกเอง — ไม่ใช่เครื่องบอทนี้

## ขั้นตอนเมื่อผู้ใช้ขอติดตั้ง
1. ถามเป้าหมายจริง 1 ประโยค: ดึงราคา / รัน EA / แค่วิเคราะห์ไฟล์?
2. เช็คดิสก์ว่าง
3. เช็คเน็ตชั้นเว็บ vs ชั้นเทรดที่เกี่ยวข้อง
4. ตัดสินใจ: ติดตั้ง / ปฏิเสธพร้อมเหตุผล / เสนอทางเลือก
5. ถ้าติดตั้ง: ใส่ **ETA เป็นนาที** และบอกขนาดโดยประมาณที่จะกิน
6. ถ้าปฏิเสธแพลตฟอร์มเทรดเพราะพอร์ตบล็อก: เสนอถอนของเก่าที่กินที่โดยไม่มีประโยชน์

## น้ำเสียงรายงาน
สั้น อ่านมือถือได้ — ขึ้นต้นด้วยคำตัดสิน (ติดตั้งได้ / ไม่คุ้ม) แล้วเหตุผล 1–2 บรรทัด
